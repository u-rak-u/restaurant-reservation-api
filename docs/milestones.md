- [x] 当日運用責任者の任命・引き継ぎと、後日の最終審査を整理する
- [x] 40席のテーブル構成と最大12名の連結ルールを確定する
- [x] 可動テーブル、移動可能エリア、配置場所の関係を確定する
- [x] 予約なし利用を含む仮決定、操作権限、自動再配置の基本ルールを確定する
- [x] 席配置の自動仮配置、柔軟決定、固定決定を確定する
- [ ] 貸切と予約なし利用の競合を含め、店舗運用とAPIが強制する安全条件を確定する
- [x] 予約なし利用を含む大人数利用の転換時間と適用時点を確定する
- [ ] 予約と予約なし利用の状態、状態遷移、誤操作訂正を確定する

現在の環境では、Docker Engineの起動、Compose設定の検証、PostgreSQL 18イメージの取得、コンテナのヘルスチェック、パスワードを使用したTCP経由のSQL接続まで完了しています。
